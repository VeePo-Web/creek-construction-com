## 2. Editorial Design Language for Imagery

Reference: FlexServices.org has hero carousels and `SilentVideo` controls — useful, but Fantasy.co-grade is **quieter**. We're closer to *Aesop, RAMP Festival, Studio Wolfgang* than to a contractor template.

### 2a. Five image archetypes (every photo is one of these)

| Archetype | Use | Layout |
|---|---|---|
| **Hero plate** | Top of project case study, full-bleed section divider | Full-width, 16:9 or 21:9, parallax on desktop, no overlay text |
| **Editorial portrait** | About page, "the crew" moments | 3:4 aspect, 60% column with white margin, hangs left or right of body copy |
| **Detail study** | Joinery, materials, hardware close-ups | 1:1 square, paired in 2-up or 3-up grids, generous whitespace |
| **Process frame** | In-progress, framing, sheathing | 4:3, asymmetric 60/40 with caption hanging in margin |
| **Ambient bleed** | Section transitions, between-paragraph rests | Full-bleed strip, 32vh tall, slow Ken-Burns drift |

`shot_type` from the AI classifier maps directly to archetype. The AI already returns `hero | elevation | detail | interior | process | wide | aerial`.

### 2b. The four video treatments

You already chose **silent autoplay loops**. Here's the discipline around it:

| Treatment | Spec | Where |
|---|---|---|
| **Atmospheric bleed** | 6–10s, silent, autoplay, loop, `playsinline`, looped seamlessly, ~720p, ≤2MB | Hero secondary, section dividers |
| **Detail loop** | 4–6s closeup of one action (sander, drill, saw), silent, looped | Inside service explainers |
| **Time-lapse plate** | 12–20s compressed build sequence, silent | One per project case study, not multiple |
| **Poster-only fallback** | Used on slow connections / reduced motion | Auto-swapped via `prefers-reduced-motion` and `Save-Data` header |

### 2c. The Ten Image Laws (codified into `IMAGE_RULES.md`)

1. **No image without `alt`** — fail loudly in dev if missing.
2. **No image without `width`/`height`** — prevents CLS.
3. **AVIF + WebP + JPG fallback**, served via `<picture>`. AVIF saves ~30% over WebP, ~50% over JPG.
4. **LQIP blur-up always** — 20px-wide base64 thumbnail, blurred, fades out on load. No spinners, no flashes.
5. **Above-the-fold hero gets `fetchpriority="high"` + `loading="eager"`** — exactly one per page.
6. **Below-the-fold images use `loading="lazy"` + `decoding="async"`**.
7. **Responsive `sizes` mandatory** — match real layout breakpoints (`(min-width:1024px) 33vw, (min-width:768px) 50vw, 100vw`).
8. **Aspect ratio locked via `aspect-ratio` CSS** — never via padding-bottom hack.
9. **No text overlaid on photo** unless the photo has a deliberate negative-space zone (only some heroes qualify).
10. **`prefers-reduced-motion` disables Ken Burns, parallax, and video autoplay** — falls back to poster.

### 2d. The Five Video Laws

1. **Always `muted`, `playsinline`, `autoplay`, `loop`** for ambient — never autoplay with sound.
2. **Always a poster image** — same first frame, ensures zero blank space if video fails.
3. **MP4 (H.264) + WebM (VP9)** — Safari needs MP4, Chrome prefers WebM (smaller).
4. **Max 2.5 MB per ambient loop** — anything bigger gets re-encoded with stronger CRF.
5. **Never more than one playing video per viewport** — IntersectionObserver pauses off-screen videos to save battery.

## 4. Component Primitives to Build

Each replaces or wraps `ProgressiveImage` / `ImageDivider`. Every primitive **degrades gracefully to evergreen** if no approved media matches.

| Component | Purpose |
|---|---|
| `<EditorialPicture />` | The atomic unit. Renders `<picture>` with AVIF/WebP/JPG, LQIP base64 blur-up, lazy loading, aspect-ratio lock, alt enforcement. |
| `<AmbientVideoBleed />` | Silent autoplay loop with poster, IntersectionObserver pause/resume, reduced-motion fallback to static poster. |
| `<MediaSlot slot="home-hero" fallback={...} />` | Pulls approved media for a named slot from Supabase. Renders fallback if nothing matches. **This is the magic** — pages don't import images, they request slots. |
| `<EditorialGallery project={slug} />` | Wraps existing `ProjectGallery`, but pulls photos from `media_metadata` instead of hardcoded imports. |
| `<ProvenanceCaption numeral="I" location="Bridgeland" year={2025} />` | Editorial line under every major media block. |
| `<ServiceMediaStrip service="decks" />` | One image + optional detail loop, used on Services page. |

## 5. The Variant Pipeline (`process-media` edge function)

Triggered when a media item is approved in `/admin/classify`. Generates everything needed for performance.

### For images:
1. Read original from `media-library` bucket
2. Generate AVIF, WebP, JPG at widths `[480, 800, 1200, 1600, 2400]`
3. Generate LQIP — 20px-wide JPG → base64 string
4. Extract dominant color (cedar-friendly fallback bg)
5. Store paths/base64 in `media_metadata.variants` (jsonb), `lqip` (text)

### For videos (.MOV → web-ready):
1. Probe duration, dimensions
2. Trim to 8s (longest ambient bleed)
3. Encode H.264 MP4 (CRF 26, ~720p) — Safari path
4. Encode VP9 WebM (CRF 32) — Chrome path
5. Strip audio entirely (silent enforced at file level — defense in depth)
6. Extract poster frame at 1.5s
7. Store in `variants.video_mp4`, `variants.video_webm`, `variants.poster`

**Tech note:** Edge functions can't run ffmpeg natively. Two options:
- **Option A (simpler):** Use Supabase's image transformation service for images, accept that videos must be pre-encoded by you before upload.
- **Option B (better):** Run ffmpeg via WASM in the edge function. Slower but works.
- **Option C (best for scale):** Trigger a worker (Modal, Replicate, or a dedicated CF Worker with R2). Out of scope for this loop — pick later if you outgrow B.

I'll build **Option B** so you don't have to pre-process videos manually. Slow but autonomous.
